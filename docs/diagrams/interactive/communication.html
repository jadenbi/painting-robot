容量由配置决定

  • 可用容量来自 RAPID 数组与队列实现。
  • 任务计数包括排队辅助动作；START 不占队列。
  • 调整容量时同步两端定义与安全检查。

接收与完成不同

  • 包 ACK 或 MSG_LAST 不代表物理绘图完成。
  • 批尾标记由运动任务执行，到位后递增。
  • 结合 Stamp 与空闲状态后，才确认本批完成。

异常与等待

  • 异常或未确认时停止续发，不重发整批坐标。
  • 小任务暂时空队列时可只发 START 唤醒余下任务。
  • 大任务可能有批间等待，未实现滑动窗口续发。
