输入选择

  • 不勾选 skill：当前确认图直接二值化。
  • 勾选 skill：先通过 API 配合规则整理结构。
  • 两种输入采用同一套后续算法与编辑流程。

几何优化

  • 有效墨迹裁边后映射到毫米画布。
  • 拟合检查误差与尺度，失败局部拆分重拟合。
  • 修改闭合轮廓后，区域填充跟随当前轮廓。

执行约束

  • 填充以分块蛇形、最近邻与局部改进减少空走。
  • 曲线采样为 MOVEL，ABB 不直接执行控制点。
  • 图像或二值图改变后，旧计划失效并重新生成。
