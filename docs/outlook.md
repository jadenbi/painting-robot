# 结合 ABB 的应用展望

[返回总览](../README.md)

当前项目验证的是平面肖像绘制链路。它的扩展价值在于把“输入表达 → 图像/几何结构 → 可编辑路径 → 受容量约束的发送 → 机器人执行”分成明确模块，使未来应用可以替换输入与末端工艺，同时复用部分路径编辑和通信基础。

以下为后续研究与工程方向，尚未作为现有系统功能实现。尤其要区分图像能够生成某种图案，与机器人已经具备执行相应材料工艺的能力。

## 从画像向多种平面任务扩展

| 场景 | 可以复用的部分 | 需要新增或替换的部分 |
| --- | --- | --- |
| 个性化文字、签名、标志与图案绘制 | 路径编辑、轮廓/区域表达、填充排序、ABB 发送确认 | 矢量/字体输入、笔顺与样式控制、版权和素材授权管理 |
| 教学演示与互动艺术装置 | 前端导入/拍照、图片确认、可选结构整理、固定语音指引 | 多作品排版、现场交互流程、人员与机器人的操作边界 |
| 平面工件标记与定位辅助 | 毫米路径、范围检查、执行确认 | 工件视觉定位、坐标标定、不同标记工具的工艺参数 |
| 点胶、涂覆与局部喷涂的路径实验 | 闭合区域、扫描填充、分块路径表达 | 工具开关与流量接口、材料覆盖模型、间距/速度/启停补偿、工艺验证 |
| 雕刻或其他接触加工研究 | 可编辑轮廓与部分轨迹组织方式 | 深度规划、接触/负载控制、专用工具、运动工艺和设备条件 |

点胶、喷涂或雕刻不能直接复用“1.5 mm 画笔、2 mm 扫描行距”作为工艺参数。它们只能先复用框架中的数据组织与规划思想，再按末端工具和材料重新建模。

## 可以推进的技术方向

**工件定位与视觉闭环。** 当前图片到纸面的映射依赖已知工作面和标定。后续可用相机识别纸张/工件姿态，计算图像到工作面的变换；在绘制后拍摄结果，与计划比较，定位缺画或偏差。相机标定、图像配准和纠错执行规则需要单独实现，现有前端拍照并不等于已有视觉闭环。

**以工具为约束的规划。** 将笔宽、排线间距、速度、抬笔高度与材料工艺作为明确参数，建立不同工具的配置与验证流程。接触式工具可以进一步研究表面高度补偿或力反馈，降低纸面/工件不平整带来的误差。这需要相应传感器或控制接口，不能通过更换图像模型实现。

**更连续的通信流控。** 当前大任务按批结束再续发，可避免缓冲溢出，但存在批间等待。若控制器增加明确的剩余容量或已消费指令序号反馈，可研究低水位补充或滑动窗口发送，在可靠性约束下提升连续性。还需定义断线、序号重复与恢复语义，不能仅提高每批上限。

**从平面扩展到曲面。** 可将二维图案投影到已知三维表面，规划姿态与工具法向；需要深度/表面模型、手眼/工件标定、可达性与碰撞检查，以及匹配的运动输出。当前 A3 二维映射与 MOVEL 采样不包含这些能力。

**模块化实验接口。** 把图像处理、结构规则、路径求解器和工具执行参数分开配置，使不同输入和算法可以在同一数据集上比较。这样可研究“结构整理对可绘制性有何贡献”“路径平滑与空走优化各改善哪一部分”，而不把所有效果归因于 AI。
